# 단방향 원격 카메라 · iPhone 2.7.0 / Galaxy 2.5.0

홈 또는 리모트의 Galaxy 카메라 실행 → 서버가 서명된 FCM 요청을 Galaxy로 전달 → Galaxy에서 사전 허용한 자동 수락 → 갤럭시 카메라 영상만 iPhone으로 WebRTC 직접 전송한다. iPhone 카메라는 열지 않고 양쪽 마이크를 사용하지 않는다. 사진과 무음 동영상은 Galaxy에서 처리해 갤러리의 GalaxyRelay 폴더에 저장한다.

## 설치와 권한

양쪽 앱을 덮어 설치하고 운영 서버를 함께 업데이트한다. Galaxy 설정 → iPhone 원격 카메라에서 내 iPhone 요청 자동 수락을 켜고, 카메라 및 전체 화면 알림 권한을 허용한다. Android 8/9에서는 갤러리 저장 권한도 필요하다. 마이크 권한은 추가하지 않는다. iPhone은 카메라·마이크 권한을 요청하지 않으며 WebView의 미디어 캡처 요청도 명시적으로 거부한다.

수신 화면을 실제 전면에 표시한 상태에서 자동 연결한다. Android가 잠금/화면 꺼짐 상태에서 전체 화면 수신 알림을 허용하면 직접 진입할 수 있다. 다른 앱을 사용 중이거나 권한/One UI 정책으로 화면 자동 열기가 제한되면 알림을 눌러야 할 수 있다. 자동 수락 API가 사용자 터치를 만들어 내는 방식은 아니다. 삼성 실기기의 잠금·화면 상태별 동작은 별도 검증 대상이다. 카메라 화면에서 다른 앱으로 이동하면 세션도 종료한다.

## 연결과 종료

- 서버는 인증·기기 호출·암호화된 SDP/ICE 연결 정보와 종료 상태만 전달한다. 영상·사진·녹화 파일·촬영 명령은 서버에 올리지 않는다.
- WebRTC에는 STUN만 설정한다. TURN·영상 중계·iPhone 송신 트랙·오디오 트랙은 없다. 직접 연결할 수 없는 네트워크에서는 실패한다.
- SDP/ICE는 기존 BLE 페어의 link key로 AES-GCM 암호화한다. AAD는 camera-signal/v1, 세션 ID, native 기기 ID, 송신 역할, 순번을 묶는다. 브라우저는 오디오 SDP를 거부한다.
- 권한은 현재 페어/세션/역할/만료 시각별 HMAC으로 제한한다. Galaxy마다 한 세션만 허용한다. 서버의 Durable Object는 암호화 연결 정보와 짧은 메타데이터만 저장하며 10분 뒤 alarm으로 삭제한다. 종료 후에는 지연된 수신 요청이 세션을 되살릴 수 없다.
- 닫기 → P2P 종료 메시지·서버 종료 → Galaxy 트랙 해제·연결 종료·화면 닫기. 저장 중인 마지막 녹화 조각은 짧게 마무리한다.
- iPhone의 1초 주기 P2P 확인 신호가 8초 끊기면 Galaxy JS와 네이티브 watchdog이 종료한다. 앱 강제 종료·네트워크 단절·웹 프로세스 정지에도 무기한 촬영하지 않는다. 처음 연결은 30~35초 제한, 한 세션은 최대 10분이다. Galaxy가 앱을 벗어나도 종료한다.
- iPhone에서 닫기/백그라운드 전환/연결 해제 시 세션을 취소하며, 늦게 도착한 start 응답도 취소한다. 로컬 상태로 과거 촬영 요청을 재시도하지 않는다.

## 촬영 범위

사진은 Galaxy 카메라의 현재 영상 프레임을 JPEG로 저장한다. 기본 영상 요청은 1280×720이며 장치/웹 엔진이 실제 해상도를 결정한다. 삼성 기본 카메라의 고해상도 정지 사진·HDR·야간 촬영 기능은 포함하지 않는다. 무음 녹화는 지원되는 WebM(VP8)/MP4로 저장하고 한 번에 최대 3분, 최대 256MB다. 정상 종료는 녹화를 마무리해 저장하지만 프로세스 강제 종료 등으로 완성하지 못한 파일은 공개하지 않고 삭제한다.

## 검증

`node tools/test-camera.mjs`: 가상 카메라를 사용한 실제 두 Chromium peer 간 연결, iPhone 무캡처, 양쪽 오디오 없음, Galaxy 사진/JPEG·무음 녹화, 닫기·8초 lease 만료·수락 전 취소, 서버에 미디어/촬영 명령이 전송되지 않음을 확인한다. 실제 카메라/마이크는 사용하지 않는다.

`node tools/test-camera-do.mjs`: 실제 로컬 Cloudflare Durable Object 런타임과 RPC·연결 정보 전달·취소 tombstone을 확인한다. Backend 단위/API 테스트는 현재 페어·역할·HMAC·만료·재전송·메모리 한도·FCM 실패/취소/인증 폐기를 검증한다. iPhone 호스트 테스트는 닫기 중복 방지, start 대기 중 닫기, 늦은 응답 취소, 원격 종료 이후 이벤트 무시를 검증한다.

실제 iPhone WKWebView ↔ Galaxy WebView 조합 및 One UI의 전체 화면 자동 열기는 이 테스트로 증명되지 않으므로 사용 기기에서 확인해야 한다.

## 2026-10-25 마무리 상태

서버 타입 검사·테스트 31개, Android 테스트 44개·debug/release 빌드·lint(오류 0개), 실제 Chromium peer 간 가상 카메라 및 로컬 Durable Object 시험을 통과했다. Android 2.5.0 code 21은 기존 개인 release 서명으로 APK를 생성했다. 운영 Worker `c39c7d8f-11ed-4c20-9f61-2271e258f503` 배포 후 health·카메라 화면/헤더·실제 DO RPC·역할 및 변조 거부를 합성 세션으로 확인했다. 실제 기기 호출·카메라·마이크는 사용하지 않았다.

GitHub Actions는 계정 결제/지출 한도 문제로 작업 시작 전에 차단됐다. iPhone 2.7.0 build 22 소스와 호스트 테스트 4개는 작성했지만 빌드/실행하지 못했으며 새 IPA는 없다. 사용자의 마무리 요청에 따라 추가 Actions 실행을 하지 않고 PR #21을 초안·미병합으로 남긴다. 마지막 검증 IPA는 2.6.0이다. 자동 연결과 실제 갤럭시/iPhone 영상 연결을 사용 완료 상태로 표현하지 않는다.

카메라 확인 신호 제한은 8초다. JS 타이머·네이티브 watchdog 확인 주기와 강제 WebView 정리 시간을 포함하면 비정상 종료 시 해제까지 약 8~11초가 걸릴 수 있다. 정상 닫기는 종료 메시지를 받으면 즉시 영상 트랙부터 해제한다.
