# Galaxy 2.1.0 · 화면 개편

Android Java native UI를 iPhone Relay의 세 탭 구성에 맞췄다. Android OS 권한 창과 기본 탐색 규칙을 그대로 사용한다. 둥근 표면·파란색 강조·큰 제목·자체 벡터 아이콘·하단 탭을 적용했다. iOS 전용 Liquid Glass API를 Android에서 사용한다고 표시하지 않는다.

## 홈

- 연결 카드: 인증 완료/연결 중/재연결 상태, Galaxy·iPhone 배터리, 마지막 전송 시간. 기존 페어링이면 새 QR 발급 대신 재연결을 우선 제공한다. 새 QR은 페어링 교체 확인 후 생성한다.
- 위치 카드: **마지막 연결 해제 위치**를 별도 표시한다. 위치 권한 상태와 **위치 권한 설정** 버튼은 기록이 없어도 보인다. 저장 좌표가 있는 현재 pair에만 지도 버튼을 표시한다.
- 사용 준비: 알림 접근/근처 기기 권한 여부와 설정 진입.

## 알림 기록

최근 최대 40개 전달 기록, 앱 아이콘/이름·시간·전송 대기 상태를 카드로 표시한다. 기본적으로 제목을 숨기며 직접 눌렀을 때 상세 내용을 볼 수 있다. 개인정보 설정에서 숨김을 해제할 수 있다. 읽기만으로 원본 알림을 제거하거나 메시지를 읽음 처리하지 않는다. 기록은 기존 Room 데이터에서 읽으며 서버를 추가 호출하지 않는다.

## 설정

위치, 알림 전달, 개인정보, iPhone 연결을 각각 분리했다. 전화·직접 SMS, 진단, 이전 PWA/서버 설정은 접힌 영역에 둔다. 기존 등록·페어링·권한·전달·암호화 옵션을 유지한다. 앱 버전을 하단에 표시한다.

## 위치는 어디에 있나

Galaxy 홈 → 마지막 연결 해제 위치. 권한이 없다면 같은 카드의 **위치 권한 설정**을 누른다. 먼저 사용 중 허용 → 다시 눌러 앱 설정 → 권한 → 위치 → 항상 허용 순서다. 설정 탭의 맨 위 **연결 해제 위치**에서도 같은 작업을 할 수 있다.

iPhone 2.1.3의 홈에도 마지막 연결 해제 위치 카드가 있다. 권한은 iPhone 앱 설정 → 연결 해제 위치 → 위치 권한 설정에서 허용한다. 구 버전에는 이 항목이 없으므로 해당 IPA로 업데이트해야 한다.

위치는 정상 연결 후 단절을 감지해야 생기며, 권한 허용만으로 측정하지 않는다. 각 기기는 자기 위치 한 개만 보관한다. 단절 후 최대 15초, 3초 재연결 취소, 최소 5분 간격은 그대로 유지한다. [동작과 OS 한계](disconnect-location.md).

## 검증

Android API 35 에뮬레이터에서 앱 실행, 하단 탭 이동, 홈/설정의 위치 권한 진입 노출, 기록 없음의 지도 숨김, 진단 숨김 및 기존 QR 교체 동작을 확인한다. 실제 Galaxy/iPhone의 Bluetooth·GPS 물리 검증은 이번 UI 시험의 범위에 포함되지 않는다. 결과는 native-tests.md 참조.
