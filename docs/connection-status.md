# iPhone 2.7.1 연결 상태 표시

홈과 설정에 동일한 연결 상태 문구·색상을 사용합니다.

| 색상 | 문구 | 판정 |
| --- | --- | --- |
| 초록 | 블루투스로 연결됨 | 인증된 BLE 연결과 최근 통신이 확인됨 |
| 파랑 | 서버를 통해 연결됨 | 앱이 열린 동안 Galaxy의 암호화된 서버 응답을 검증하고 ACK 완료 |
| 주황 | 연결 시도 중… | 확인된 연결 없이 블루투스 또는 서버 연결을 시도 중 |
| 빨강 | 연결이 끊어졌습니다 | 확인된 연결도 진행 중인 연결 시도도 없음 |

블루투스 연결이 우선입니다. 서버 연결이 확인된 동안에는 블루투스 재연결이나 다음 서버 동기화를 시작해도 파란색을 유지합니다. 서버가 요청을 접수했다는 응답만으로 연결 완료를 표시하지 않습니다. 빈 알림 목록도 인증된 Galaxy 응답과 ACK가 확인되면 연결 완료로 표시합니다.

서버 확인은 메모리에서 최대 120초간 유효합니다. 확인 실패, 오프라인 전환, 앱 백그라운드 전환 및 연결 해제 시 초기화하며, 이전 요청의 늦은 응답이 상태를 되돌리지 못하도록 구분합니다. 블루투스가 꺼져 있거나 권한이 없어 시도할 수 없는 상태는 블루투스 연결 시도로 표시하지 않습니다.

이번 변경은 iPhone 앱 업데이트로 적용합니다. 기존 Galaxy 앱·서버 API·페어링 정보를 사용합니다. 리모트의 연결 문구도 “블루투스로 연결됨”과 초록색으로 맞췄습니다.

## 검증

네 가지 상태의 우선순위, 서버 확인 만료·실패, 실제 형식의 암호화 응답과 ACK, 다른 기기의 응답 거부, 백그라운드 전환 중 응답 무시, 오프라인 초기화를 자동 테스트합니다. 시뮬레이터에서는 초록·파랑·주황·빨강 상태를 합성 데이터로 각각 캡처합니다. 실제 운영 기기에 테스트 요청을 보내지 않습니다.

2026-10-25 [최종 CI 실행](https://github.com/simzaekong/galaxy-relay/actions/runs/40170149854) 성공: 프로토콜 테스트 51개, 앱 테스트 48개, 총 99개 통과. iPhone 실기기용 Release 컴파일·unsigned IPA 패키징·시뮬레이터 테스트·화면 캡처·업로드를 완료했습니다. 네 가지 상태의 원본 화면 캡처를 확인했습니다.
