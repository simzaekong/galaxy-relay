# 알림함 디자인 · 2026-10-10

현재 PWA는 밝은 회색 바탕, 불투명한 카드, 보라색 강조와 시스템 글꼴을 사용하는 알림함이다. 큰 잠금화면 시계·배경·유리 효과 대신 날짜, 읽지 않은 개수, 연결 상태, 검색과 분류를 위에서부터 배치했다. iOS 시스템 Push 배너를 변경하는 기능은 아니다.

## 참고한 레퍼런스

- [Linear Inbox](https://linear.app/docs/inbox): 절제된 알림함과 검색·상세의 정보 계층.
- [Notion Inbox](https://www.notion.com/help/updates-and-notifications): 관련 알림 묶음, 읽음 상태와 필터.
- [Material 3 Lists](https://m3.material.io/components/lists/overview): 아이콘·주요 텍스트·보조 텍스트·시간의 구분.

제품 이미지나 코드를 복사하지 않고 이 프로젝트의 작은 화면과 기존 제스처에 맞춰 자체 CSS·SVG로 구현했다. 외부 CDN·폰트·유료 라이브러리를 추가하지 않았다.

## 현재 화면과 동작

- 검색창과 전체/앱/문자/전화 분류가 항상 보인다.
- 묶음은 가장 최근 알림 날짜를 기준으로 오늘/어제/날짜 구역에 배치한다. 한 묶음에 이전 날짜의 메시지도 들어갈 수 있다. 묶음 개수와 펼치기 표시를 제공한다.
- 개별 알림을 누르면 모바일에서는 하단 상세 화면을 연다. 본문 기록은 남고 읽지 않은 개수만 줄어든다.
- 상세를 한 번 더 누르면 기존 Galaxy 원본 열기를 요청한다. 별도 열기·삭제 버튼은 추가하지 않았다.
- 왼쪽으로 밀어 원본 Galaxy 알림과 PWA 기록을 삭제하는 동작을 유지한다.
- 답장을 지원하는 원본 알림에는 본문 아래 입력창과 답장 전송을 표시한다. 암호화·중복 전송 방지·잠금 조건은 기존과 같다.
- 설정을 연결/알림, 개인정보, 데이터 관리, E2EE로 구분했다. 체크박스는 키보드로도 사용할 수 있다.
- 시스템 밝기 모드에 따라 라이트/다크 색상이 바뀐다. 320/390/430/1024px에서 화면 넘침과 상세 경계를 확인했다.

glass.js와 기존 배경은 이전 구현 참고용으로 소스에 보존하지만 현재 앱에서 import하지 않는다. 빌드와 Service Worker 정적 캐시에서도 제외한다. 새 정적 캐시는 이전 버전 캐시만 교체하며 IndexedDB 알림·기기 인증·E2EE 키를 지우지 않는다.

## 업데이트

기존 홈 화면 PWA를 인터넷 연결 상태에서 닫았다 다시 연다. 새 Service Worker가 적용되면서 한 번 새로고침될 수 있다. 이번 디자인 변경 때문에 Android APK를 다시 설치할 필요는 없다. 답장은 이미 제공한 APK 1.2.0 이상에서 사용한다.
