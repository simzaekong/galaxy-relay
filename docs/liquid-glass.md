# 이전 구현: 알림 카드의 리퀴드 글래스

2026-10-10 디자인 변경으로 현재 배포 앱에서는 유리 렌더러와 배경을 사용하지 않는다. 아래는 이전 구현 기록이다. [현재 알림함](inbox-design.md).

알림과 상세 카드의 배경은 WebGL 셰이더로 그린다. 둥근 사각형 표면의 법선과 굴절률 1.47을 사용해 배경 좌표를 휘게 하고, 가장자리의 RGB 파장을 조금씩 달리 샘플링해 색 분산을 표현한다. 곡면의 반사광, 안쪽 밝기 변화, 약한 확대를 함께 적용한다. 버튼의 글자·아이콘·본문은 캔버스가 아니라 기존 DOM으로 남아 검색·접근성·선택·터치 동작을 유지한다.

이 효과는 제공한 고정 배경 `/images/wallpaper.png`를 광학적으로 변형한다. 다른 DOM, 알림 내용, 사진·영상 또는 iOS 화면 전체를 캡처하거나 굴절하는 기능은 아니다. Apple의 네이티브 Liquid Glass 재질 API를 사용하는 것도 아니다. 모든 셰이더는 프로젝트 내 원본 코드이며 외부 런타임, CDN, 유료 리소스 없이 정적 파일만 사용한다.

Safari의 SVG `backdrop-filter: url(...)` 지원 문제 때문에 해당 기능을 요구하지 않는다. [WebKit 이슈](https://bugs.webkit.org/show_bug.cgi?id=245510)를 참고한다. WebGL을 사용할 수 없거나 컨텍스트가 손실되면 기존 투명 CSS 카드로 돌아간다. 접근성의 투명도 감소 설정에서는 렌더러를 실행하지 않고 불투명 스타일을 사용한다. iPhone 실기기의 GPU·열·배터리·메모리 상황에서 같은 품질이나 성능을 보장하는 시험은 아직 수행하지 않았다.

## 렌더링과 개인정보

- 숨겨진 WebGL 컨텍스트 하나를 공유하고, 보이는 카드에만 2D 스냅샷을 복사한다. 원본 버퍼를 유지해 카드마다 안전하게 복사한다.
- 광학 캔버스는 동시에 최대 16개, 픽셀 배율은 최대 1.5, 긴 상세의 렌더 높이는 최대 800 CSS px로 제한한다. 화면 밖 카드·교체된 목록의 캔버스는 해제한다.
- 스크롤·크기 변경·터치·테마 변경 때만 최대 약 30fps로 갱신하고 정지 상태에서는 계속 렌더링하지 않는다. 앱이 숨겨지면 프레임 예약을 취소한다. 삭제 시 짧은 CSS 이동 동안에만 추가 갱신한다.
- 연결 폼·검색 패널·상세 높이 변경 및 상세 내부 스크롤 때도 배경 좌표를 맞춘다.
- 배경 파일만 GPU 텍스처로 올린다. 알림 본문·계정·토큰을 캔버스나 셰이더로 보내지 않는다. API·알림 저장 방식·Galaxy 명령은 기존과 같다.
- 새 모듈도 Service Worker의 정적 리소스 캐시에 포함한다. 알려진 오프라인 상태에서는 캐시된 앱 화면을 먼저 사용한다. 저장된 연결 여부도 오프라인에서 적용한다.

## 재현

로컬 Backend를 8787에서 실행하고 `web`에서 `npm run build`, `npm run test:browser`를 실행한다. WebKit 엔진 설치 후 `npm run test:webkit`로 그래픽 시험을 실행할 수 있다. Windows WebKit에서 오프라인 `page.reload`는 내부 탐색 오류가 반복되어 미검증으로 남아 있으며 전체 성공으로 처리하지 않는다. Chrome의 오프라인 렌더링 시험과 WebKit 온라인 그래픽 시험을 구분한다.

`node scripts/preview.mjs`는 사용자 기록 없이 합성 데이터를 렌더링해 미리보기를 만든다. 배포 주소를 첫 인자로 주면 해당 정적 파일을 검증한다. 두 번째 인자 `--webkit`은 WebKit 미리보기를 생성한다. 이 미리보기의 API 응답은 브라우저 내부 모의다. 새 버전의 물리 iPhone 인수 시험은 별도로 필요하다.
